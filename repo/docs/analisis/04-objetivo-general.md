# 04 · Objetivo General

## Objetivo General

Diseñar una **plataforma web de alfabetización en Inteligencia Artificial para estudiantes K-12** que permita el aprendizaje interactivo mediante módulos y actividades pedagógicas adaptadas al nivel escolar, el seguimiento individualizado del progreso académico y la gestión integral del contenido educativo por parte de docentes y administradores, aplicando las metodologías de Ingeniería de Software para garantizar calidad, trazabilidad y escalabilidad del sistema.

---

## Desglose del Objetivo

| Componente | Descripción |
|------------|-------------|
| **¿Qué?** | Plataforma web de alfabetización en IA |
| **¿Para quién?** | Estudiantes K-12, Docentes y Administradores |
| **¿Cómo?** | Módulos interactivos, actividades pedagógicas, retroalimentación inmediata |
| **¿Con qué garantía?** | Metodologías de Ingeniería de Software: trazabilidad, calidad y escalabilidad |
| **¿Qué logra?** | Aprendizaje activo de IA + seguimiento del progreso + gestión pedagógica completa |
